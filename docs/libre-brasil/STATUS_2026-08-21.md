## Safety decision

No Android binary, proprietary Abbott library, protected authentication logic,
or abandoned third-party OOP endpoint was incorporated. A normalized provider
status cannot cause Trio to publish a successful pairing. Native support remains
blocked until a lawful, iOS-compatible backend also implements NFC transport and
BLE authentication/decryption.

## Immediate operational plan

The user's available Android phone will run Juggluco and own the sensor BLE
connection. Juggluco uploads to the existing Nightscout instance; Trio uses its
built-in Nightscout CGM source. This is the only end-to-end path identified today
that can be deployed without pretending the native Gen2 driver is complete.
